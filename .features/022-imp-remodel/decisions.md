# Feature 022: Decisions

- **Same rig and proportions.** Every animation, collider and gameplay
  number stays the same. Only the look changes.
- **Details go in the paint, forms in the sculpt, and the high-to-low
  bake keeps both crisp at 7.5k triangles.** This is the kids' pipeline
  from feature 015.
- **Rune markings are painted, not emissive.** Emissive bits are
  reserved for the eyes, so the imp's glow stays readable as "where it
  is looking".
