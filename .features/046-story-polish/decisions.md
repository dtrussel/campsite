# Feature 046: Decisions

- **Three lights, kept apart in every line:**
  - the moon's light, which the Moon-Eater swallowed (the shards are bits of it);
  - Mum's lantern, whose light was drunk and comes back in the true ending;
  - the Moon Lantern, the first rangers' stone lantern by the tent.

  Only the last is ever "the Moon Lantern".
- **Notes are a speaker, not a new screen.** A `note` line on a dawn card reuses the card, the voice-by-id rule and Mum's portraits (it gives the unused faces a job). Her notes are capped at 60 characters, like any card line. 041 can list the same line ids in a journal.
- **Dawn lines don't state game state.** The lantern only brightens when shards are fed, so "it glows when we feed it" became "maybe the lantern wants them".
- **The true ending is three pages.** Page 1 has the Moon-Eater falling apart, page 2 the golem, page 3 Mum. That keeps "at most two lines per card".
- **No "Try again?" in the defeat line.** The end screen's Again button already asks.
- **Creature descriptions show once per run, under the existing warning banner** (it stays up 2 s longer). Imps get a banner only for that first introduction.
- **Place names come from the map as built.** The SE landmark is a giant stump with toadstools, so it is the Fairy Ring, not an oak. "The Hollow" is kept for the deep woods only.
- **Requirements and ADRs keep their original wording.** They record what was asked. The pitch, README and design spec are updated.
