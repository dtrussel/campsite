# Feature 048: Decisions

- **Measured against the sheet.** Landmarks are read off the front and side turnaround views as fractions of the height from the feet to the top of the cap (sticks excluded). `MEASURE=1` prints them for the model:

  | Landmark | Sheet | Model |
  |---|---|---|
  | Stick tops | 1.14 | 1.134 |
  | Chin | 0.576 | 0.570 |
  | Shoulders (trunk top) | 0.555 | 0.562 |
  | Window centre | 0.39 | 0.388 |
  | Hips (trunk bottom) | 0.18 | 0.175 |
  | Hands | 0.15 | 0.147 |
  | Head width, with the ears | 0.47 | 0.457 |
  | Cap width | 0.38 | 0.386 |
  | Face width | 0.295 | 0.293 |
  | Trunk width | 0.26 | 0.244 |
  | Arm span | 0.51 | 0.499 |
  | One leg | 0.14 | 0.150 |
  | Head depth | 0.26 | 0.339 |
  | Trunk depth | 0.26 | 0.263 |

- **The head is deeper than the sheet's.** The bob's back shingles hang off the back of the head, and the ears tilt forward, which together add about 0.08. Pulling the cap in further made the back of the head bald. The side silhouette still reads like the sheet, so this stays.
- **Same height, about 0.75 m to the cap.** The scenes that place the golem (`MoonEaterVisual`, `TitleBackdrop`) need no changes.
- **Warmer wood than the Moon-Eater.** The face and most shingles use a warm tone, like the sheet. The Moon-Eater's weathered grey is kept for a few shingles.
- **The crescent glows on its own (`Body_Moon`).** In one mesh with the window it vanished into the glow. Now the window is a deeper amber and the crescent a pale gold, as on the sheet.
- **The front fringe is short.** From the gameplay camera (52° down) a longer fringe hid the eyes.
- **Curled up, the arms fold forward and in** (x -0.75, z ±0.45). Straight forward, the longer arms stuck out like stumps.
