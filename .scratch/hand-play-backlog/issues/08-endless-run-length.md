# How long an endless run lasts

Status: ready-for-human
Blocked by: none

Endless mode (042) is tested by the smoke test, which skips the clock and puts the fire out by hand. Nobody has played an endless run through yet ([endless mode](../../endless-mode/spec.md)).

- [ ] Play an endless run until it ends. Which night does it end on, and how long did it take (minutes)? Note the hero and whether the companion was set to help.
- [ ] Does the +10% mob HP per night after 7, with more heavy and sneaky mobs, make the end come from a fair, rising pressure, or from one sudden wall?
- [ ] Is the run too long for a kid's session (it has to be won back each night with no end in sight), or does it end too soon to feel like a challenge?
- [ ] Do Glow Lanterns (and tool tiers) give the shards a use worth chasing when the Moon Lantern is already lit?
- [ ] Does "New record!" on the end screen, and the best under Endless on the title, make a kid want to go again?
