# Windows build checks

Status: ready-for-human
Blocked by: none

These need the exported build on Windows, with a real GPU, and one slow laptop.

- [ ] The boot splash shows at start-up ([029](../../../docs/history/features/029-key-art-splash/test-plan.md)).
- [ ] The settings survive a restart ([016](../../../docs/history/features/016-audio-and-feel/test-plan.md)).
- [ ] Quitting mid-run, relaunching and pressing Continue resumes the run ([020](../../../docs/history/features/020-run-modes-and-autosave/test-plan.md)).
- [ ] The pause-menu Blur switch acts at once, and is remembered after a restart ([031](../../../docs/history/features/031-concept-look-pass/test-plan.md)).
- [ ] The FPS is about the same as v0.25 with the post pass, the 16-tap bokeh, the sharpen, the prop outlines, the tree canopies and the grass tufts. Note the numbers ([031](../../../docs/history/features/031-concept-look-pass/test-plan.md)).
- [ ] On a slow laptop, the frame rate holds with the fireflies on ([024](../../../docs/history/features/024-living-world/test-plan.md)).
