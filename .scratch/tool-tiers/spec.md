# Tool tiers

Status: done

From the 2026-10 brainstorm, planned as feature 040 and never started. Triaged on 2026-10-20 and split into tickets in `issues/`; the `Blocked by:` lines give the order.

## Plan

Rough size: **M**.

### Goal
Turn the one-off signature crafts into a small upgrade path, and give Glow Shards a second, competing use against the Moon Lantern.

### Scope
- **Leo:**
  - Stick;
  - **Sturdy Stick** (today, +2 damage);
  - **Ember Stick** (hits leave a short burn: 1 damage/s for 3 s, and the stick gives a small personal light at night, with no mob slow);
  - **Blaze Stick** (the burn also splashes onto mobs right next to the target, and the light grows a little; decided 2026-10-21).
- **Nela:**
  - Slingshot (today, more reach);
  - **Double Sling** (every 3rd shot fires two pebbles);
  - **Glow Sling** (pebbles pierce and briefly light the target).
- **Costs:** tier 1 is today's signature craft. **Tier 2** costs Wood + Scrap + 2 Glow Shards, and **tier 3** costs Scrap + Clay + 4 Glow Shards. Every shard spent there is one the lantern doesn't get (it needs 11 in Chapter 1).
- **HUD:** the attack slot shows the tier pip.

### Systems touched
- `scripts/characters/hero_definition.gd`: `signature_tiers: Array[{recipe, damage_bonus, range_factor, effect}]` replaces the single signature fields.
- `scripts/core/crafting_manager.gd` (`_signature_owner`): the next tier becomes available once the previous one is owned. New `resources/recipes/*.tres`.
- `scripts/player/player_controller.gd`, `scripts/companions/companion_controller.gd`, `scripts/characters/pebble_shot.gd`: the burn, double and pierce effects.
- `scripts/core/save_manager.gd`: `signature` becomes a tier int, and old booleans map to tier 1.

### Depends on
036 (the shard economy, done). It reuses the damage, reach and bounce hooks that perk cards (039) adds, so it starts after perk cards ticket 05. It also waits on **hero-core** (`.scratch/hero-core/`), so the tier effects are written once in the shared Hero module instead of in both controllers.

## Decisions so far

- **From the 2026-10 brainstorm.** The user chose story (B) and choices / meta (C), with an **adventure** tone (see `docs/design/story.md`), and asked for the roadmap first. This folder is a plan only: nothing is built yet.
- **The tiers live on the hero data,** so a new hero brings their own tool path.
- **Per run only** (decided 2026-10-20), as signatures are today. The meta profile (041) may later grant a starting tier.
- **Resin and Mushrooms stay cut** (decided 2026-10-20). Playtest 1 (044) removed them, so the costs use Wood, Scrap, Clay and shards, and the "items get real uses" part (longer torches, Brave Brew) is dropped. If it's still wanted, it becomes its own small spec using existing items.
- **The Ember Stick's light is a small personal light,** with no mob slow, and it doesn't stack with torches (decided 2026-10-20).
